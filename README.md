# Minecraft Mods

Monorepo for my Minecraft Fabric mods, each in its own subdirectory.

| Mod | MC Version | Description |
|---|---|---|
| [no-piston-entity-push](./no-piston-entity-push) | 1.21.11 | Disable piston pushing of item entities |

## Development

Each mod is independent — enter its directory and run `./gradlew build` to compile.
